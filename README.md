# EVENTBOX Prototype

Prototype single-page application React + Vite untuk demo startup event planning EVENTBOX.

## Menjalankan project

```bash
npm install
npm run dev
```

Buka URL yang ditampilkan Vite (biasanya `http://localhost:5173`).

## Demo login

- Email: `demo@eventbox.id`
- Password: `123456`

## Fitur yang sudah disimulasikan

- Landing page / marketplace event
- Eksplorasi kategori
- Paket event
- Filter paket
- Detail paket
- Custom paket dengan kalkulasi real-time
- Pilih vendor
- Checkout dan DP 30%
- Simulasi pembayaran
- Order tracking
- Login / dashboard / profile / riwayat pesanan
- Penyimpanan state demo melalui localStorage

> Gambar menggunakan URL publik Unsplash agar prototype tetap ringan. Ganti URL gambar dengan asset sendiri bila digunakan untuk produksi/presentasi offline.
